# dsh-life-planner · 设计文档

> 版本：v0.2（已确认） · 状态：设计定稿，待排开发计划
> 目标用户：非开发者，日常「生活 / 时间管理」场景

## 1. 目标

一个挂在 DSH 侧边栏的生活时间管理插件，核心是：**用一句话记任务、到点用 Windows 通知栏提醒、倒计时看关键日期、正向计时的专注、日历总览、专注时长与打卡热力图**。

## 2. 模块设计

### 2.1 任务 / 待办
- 一句话添加：AI 自动解析「做什么 + 什么时候 + 是否重复」，**不解析优先级**。
- 字段：标题、备注、截止时间、重复（每天 / 每周 / 每月 / 每年 / 工作日）。
- 状态：待办 → 已完成（可开「完成需确认」开关）。
- 逾期自动标红、置顶。
- 不做：优先级、子任务、开始时间。

### 2.2 提醒 / 通知
- 到期提醒精确到分钟。
- **提前提醒规则（核心）**：
  - 截止时间距今 **≥ 2 天**（后天及更晚）→ 在**截止前一天**额外提醒一次。
  - 距今 **< 2 天**（明天或当天）→ **只在到期那一刻提醒**，不提前。
- 重复任务每次到期都提醒。
- **Windows 原生通知**：切到其他窗口也弹系统通知。
- 应用内富弹窗，三个动作：完成 / 稍后提醒 / 忽略。
- 稍后提醒可选：5 分钟 / 15 分钟 / 1 小时 / 明天。
- 自定义提醒音 + 样式（普通 / 成功 / 注意 / 紧急）。
- **补弹**：桌面端完全关闭期间的提醒暂存，下次打开补弹。

### 2.3 倒计时
- 添加：标题 + 目标日期（如「六级考试 · 12月14日」）。
- 显示「距离 X 还有 Y 天」，Y 每天自动更新。
- 列表按最近到期排序。
- 不做「已过 Y 天」方向。

### 2.4 日历视图
- 日 / 周 / 月三种视图。
- 视图上直接显示对应任务（按截止时间铺到对应日期）。
- 点某天看当天要做什么。
- 不支持外部日历导入。

### 2.5 专注（正向计时）
- 点「开始」往上走（0:00 → 0:01 → …），可暂停、结束。
- 结束时记录本次专注时长。
- 可关联某条任务（可选）。
- 无固定时长、无自动休息、无音乐。

### 2.6 统计
- 累计专注时长。
- 打卡热力图：绿格子，当天完成 ≥1 条任务 或 有专注，就点亮一格。

### 2.7 界面
- DSH 插件侧栏入口（与已装待办提醒并列）。
- 右侧常驻待办条：收起显示下一件事「到期时间 + 标题」，逾期变红。
- 主面板页签：待办 / 倒计时 / 日历 / 专注 / 统计。
- 治愈系视觉风格：本期不做，功能跑通后美化。

### 2.8 数据
- 本地持久化（数据存本机，不联网）。
- 本期不做导出 / 云端同步。

## 3. 非目标（本期明确不做）

优先级、子任务、开始时间、语音输入、白噪音/音乐、周报/月报、外部日历导入、纪念日倒计时（已过 Y 天）、治愈系视觉、导出、云端同步。

## 4. 关键规则速查

| 规则 | 说明 |
|------|------|
| 提前提醒阈值 | 截止距今 ≥2 天才在截止前一天提醒；<2 天只到期提醒 |
| 专注 | 纯正向计时，无固定时长/休息/音乐 |
| 倒计时 | 仅「距离 X 还有 Y 天」，每天自动更新 |
| 热力图点亮条件 | 当天完成 ≥1 任务 或 有专注 |
